# 阿瓦隆产品文案规范

## 适用范围
普通玩家可见的标题、按钮、说明、状态、错误、空状态、无障碍名称和浏览器元数据。

## 语气
像清晰可靠的裁判一样说明当前状态和下一步；只在角色揭示、阶段标题和胜负结果中加入轻度世界观氛围。

## 术语来源
领域概念以 `CONTEXT.md` 为准。中文界面固定使用：房间、房间列表、座位、玩家、房间拥有者、加入游戏、移至 X 号空座位、帕西维尔与莫甘娜、Merlin 候选、任务队伍、队伍表决、任务牌、对局记录、成功、失败。

## 状态与错误
只显示会阻塞玩家或需要玩家理解的状态。阻断性错误说明发生了什么以及下一步操作；不得透传服务端原始错误。

加入与换座错误固定使用“房间已满”“游戏已经开始”“房间不存在或已解散”“本浏览器已经加入该房间”“该空座刚刚被其他玩家占用”“当前座位会话已失效”“只有房间拥有者可以执行此操作”“房间拥有者退出时需要解散房间”。普通加入不出现“选择座位”或“重新选择座位”。

## 禁用表达
普通玩家界面不出现局域网、MVP、服务端权威、凭据、会话、轮询频率、filtered player view 等实现语言。

## 中文与标点
普通界面使用自然简体中文；按钮使用明确动词；中文句子使用全角标点；同类数字、单位和标点格式保持一致。

开发管理文案因明确面向技术用途而不受本规范限制，但必须保持在普通生产路径之外。
