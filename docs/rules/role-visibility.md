# 角色视野矩阵（MVP）

## 基础角色

| 观察者 | 可见信息 |
|---|---|
| 普通好人 | 只知道自己的阵营和身份 |
| 梅林 | 所有坏人玩家的座位 |
| 刺客 | 其他坏人玩家的座位；不能直接知道梅林是谁 |
| 普通坏人 | 其他坏人玩家的座位 |

MVP 不启用 Mordred 和 Oberon，因此梅林能看到全部坏人，坏人也能互相认识。

## 扩展角色加入后的变化

| 角色 | 视野变化 |
|---|---|
| Mordred | 坏人身份，但不出现在梅林视野中 |
| Oberon | 不出现在其他坏人视野中，也看不到其他坏人 |
| Morgana | 在 Percival 视野中伪装成梅林 |
| Percival | 能看到梅林；如果有 Morgana，则同时看到梅林和 Morgana |

## 实现约束

- 角色身份和完整视野只能由服务端保存。
- 每个客户端只能收到自己的过滤视图。
- 不能只在前端隐藏角色名称。
- 任务秘密选择结果在全部提交前不能公开。
- 任务结果揭示时只能公开成功/失败数量或规则要求的结果，不公开单张牌对应的玩家。
