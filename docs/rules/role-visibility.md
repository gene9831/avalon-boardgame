# 角色视野矩阵

## 基础角色

| 观察者 | 可见信息 |
|---|---|
| 普通好人 | 只知道自己的阵营和身份 |
| 梅林 | 所有坏人玩家的座位 |
| 刺客 | 其他坏人玩家的座位；不能直接知道梅林是谁 |
| 普通坏人 | 其他坏人玩家的座位 |

当前不启用 Mordred 和 Oberon，因此 Merlin 能看到全部邪恶座位，邪恶玩家也能互相认识。Merlin 和邪恶玩家都只能获得阵营座位信息，不能由此知道某个邪恶玩家的精确角色是 Assassin、Morgana 还是 Minion。

## 开局身份辨认

开局在首次组队前，每名玩家独立完成自己的身份辨认流程，彼此不互相阻塞：

1. **身份确认**：每名玩家只查看并确认自己的完整角色信息；此时不释放任何其他座位的阵营视野。
2. **线索辨认**：邪恶玩家、Merlin，以及启用成对角色时的 Percival，在确认身份后立即进入各自的线索视图并再次确认；没有额外座位知识的角色在身份确认后直接完成。
3. **完成等待**：已完成玩家返回正常圆桌，可只读查看自己的身份与已知信息；其他玩家仍可同时停留在身份牌或线索辨认阶段。

公共状态只公开“已完整完成的玩家数 / 总玩家数”，不公开任何玩家的个人阶段或完成座位。所有玩家完成后才原子进入首次组队；正常游戏继续保留上述授权视野。Percival 的候选集合与已知邪恶集合是两种不同知识，不能共用字段。

## 扩展角色加入后的变化

| 角色 | 视野变化 |
|---|---|
| Mordred | 坏人身份，但不出现在梅林视野中 |
| Oberon | 不出现在其他坏人视野中，也看不到其他坏人 |
| Morgana | 在 Percival 视野中伪装成 Merlin；仍是普通邪恶互认和 Merlin 视野中的邪恶座位 |
| Percival | 同时看到 Merlin 与 Morgana 两个不可区分的候选座位 |

## 实现约束

- 角色身份和完整视野只能由服务端保存。
- 每个客户端只能收到自己的过滤视图。
- 开局辨认信息只能在当前玩家完成身份确认后向该玩家释放；前端遮挡不是安全边界。
- 匿名确认进度不能包含已确认玩家的座位或身份。
- 公开的 boardgame.io `ctx`、active-player move 计数或其他框架元数据不能编码辨认确认者的座位。
- 实时与持久化游戏日志都不能保留辨认确认者的座位。
- 不能只在前端隐藏角色名称。
- 队伍投票未结算时，可以公开哪些玩家已经提交，但只能向每名玩家返回自己的赞成或反对；全员完成后才同时公开逐玩家投票明细。
- 任务秘密选择结果在全部提交前不能公开。
- 任务结果揭示时只能公开成功/失败数量或规则要求的结果，不公开单张牌对应的玩家。
