# Avalon 规则来源

## 采用版本

本项目暂以 **The Resistance: Avalon 原版独立游戏（2012）** 作为 MVP 的规则基准，支持 5–10 名玩家。

不将以下版本的规则混入 MVP：

- Avalon Big Box
- Quest
- Lady of the Lake
- Lancelot、Excalibur、Plot Cards 等扩展模块

## 来源

- 出版方页面：<https://indieboardsandcards.com/our-games/the-resistance-avalon/>
- 原版英文规则书 PDF 镜像：<https://cdn.1j1ju.com/medias/a6/dc/c1-the-resistance-avalon-rulebook.pdf>

PDF 是 8 页扫描版原版规则书，项目同时保留原始 PDF 和本目录下的整理文档。原始 PDF 仅作为开发参考；项目 UI 暂不复用原版美术、扫描图或牌面图片。

## MVP 规则范围

首版启用：

- Loyal Servant of Arthur
- Minion of Mordred
- Merlin
- Assassin
- Percival（创建新房间时与 Morgana 成对默认启用）
- Morgana（创建新房间时与 Percival 成对默认启用）

首版暂不启用：Mordred、Oberon、Lady of the Lake、Targeting、Plot & Loyalty Cards。
