# 阿瓦隆原版规则摘要（MVP）

本文件是对原版规则书的编码摘要，不替代原始规则书。遇到争议时，以 `the-resistance-avalon-rulebook.pdf` 为准。

## 游戏目标

- 好人完成 5 个任务中的 3 个，且刺客未能在最后阶段指出梅林，好人获胜。
- 坏人让 3 个任务失败，坏人获胜。
- 同一轮连续 5 个队伍提案被否决，坏人立即获胜。

## 开局

1. 根据玩家人数确定好人和坏人数量。
2. 随机分配身份牌，每名玩家秘密查看自己的身份。
3. 随机确定首位队长。
4. 基础规则下，坏人互相认识；梅林知道坏人身份。
5. 角色牌不能在游戏中公开展示，也不能直接公开角色名称。

|---:|---:|---:|

| 8 | 5 | 3 |

## 每轮流程

### 1. 组队阶段

当前队长选择指定数量的玩家组成任务队伍。队长可以选择自己，也可以不选择自己。

### 2. 队伍投票

- 所有玩家同时提交赞成或反对。
- 赞成票严格超过半数，队伍通过。
- 平票视为否决。
- 队伍被否决后，队长顺时针移动到下一名玩家。
- 同一轮连续 5 次否决，坏人获胜。

### 3. 任务阶段

- 任务队伍成员各自秘密提交成功或失败。
- 好人必须提交成功。
- 坏人可以提交成功或失败。
- 提交结果应被收集并打乱后再揭示。
- 默认情况下，只要出现一张失败牌，任务就失败。
- 7 人及以上时，第 4 个任务需要至少两张失败牌才会失败。

### 4. 结算

- 任务成功：记录一次好人成功。
- 任务失败：记录一次坏人成功。
- 队长顺时针移动。
- 进入下一个任务，直到触发胜负条件。

## 刺杀阶段

如果好人完成 3 个任务，坏人进入最后机会：

1. 坏人讨论并选择刺客。
2. 刺客选择一名好人并指认其为梅林。
3. 指认正确，坏人获胜；否则好人获胜。

## 可选角色规则摘要

这些角色暂不进入 MVP：

- **Percival**：开局知道梅林；加入 Morgana 后无法仅凭视野区分二者。
- **Morgana**：在 Percival 的视野中伪装成梅林。
- **Mordred**：不会被梅林看到。
- **Oberon**：不向其他坏人公开，也不获得其他坏人的身份信息。

启用这些角色后，需要扩展角色视野矩阵和开局信息脚本，不能只在角色列表中增加名称。
