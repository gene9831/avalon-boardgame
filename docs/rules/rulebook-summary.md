# 阿瓦隆原版规则摘要

本文件是对原版规则书的编码摘要，不替代原始规则书。遇到争议时，以 `the-resistance-avalon-rulebook.pdf` 为准。

## 游戏目标

- 好人完成 5 个任务中的 3 个，且刺客未能在最后阶段指出梅林，好人获胜。
- 坏人让 3 个任务失败，坏人获胜。
- 同一轮连续 5 个队伍提案被否决，坏人立即获胜。

## 开局

1. 根据玩家人数确定好人和坏人数量。
2. 随机分配身份牌，每名玩家秘密查看自己的身份。
3. 随机确定首位队长。
4. 基础规则下，坏人知道哪些玩家属于邪恶阵营；梅林知道哪些玩家属于邪恶阵营，但双方都不知道其他坏人的精确角色。
5. 每名玩家只能私下查看自己的角色牌，不能向其他玩家公开展示或直接公开角色名称。

线上版在首次组队前依次进行“查看自己的身份”“邪恶阵营辨认同伴”“梅林辨认邪恶阵营”“帕西维尔辨认梅林候选”四个步骤。未启用帕西维尔与莫甘娜时跳过最后一步。当前版本不显示或使用倒计时；每个步骤必须由该步骤的全部参与者确认后才会结束。

## 每轮流程

### 1. 组队阶段

当前队长选择指定数量的玩家组成任务队伍。队长可以选择自己，也可以不选择自己。

### 2. 队伍投票

- 所有玩家同时提交赞成或反对。
- 在线版可以公开哪些玩家已经提交以及 `x/n` 提交进度，但在全员完成前不得公开任何玩家的赞成或反对。
- 全员完成后，所有玩家的赞成或反对同时公开。
- 赞成票严格超过半数，队伍通过。
- 平票视为否决。
- 队伍被否决后，队长顺时针移动到下一名玩家。
- 同一轮连续 5 次否决，坏人获胜。

### 3. 任务阶段

- 任务队伍成员各自秘密提交成功或失败。
- 好人必须提交成功。
- 坏人可以提交成功或失败。
- 提交结果应被收集并打乱后再揭示。
- 默认情况下，只要出现一张失败牌，任务就失败。
- 7 人及以上时，第 4 个任务需要至少两张失败牌才会失败。

### 4. 结算

- 任务成功：记录一次好人成功。
- 任务失败：记录一次坏人成功。
- 队长顺时针移动。
- 进入下一个任务，直到触发胜负条件。

## 刺杀阶段

如果好人完成 3 个任务，坏人进入最后机会：

1. 坏人讨论并选择刺客。
2. 刺客选择一名好人并指认其为梅林。
3. 指认正确，坏人获胜；否则好人获胜。

## 可选角色规则摘要

创建新房间时默认成对启用以下角色，也可以在创建时关闭并恢复基础角色：

- **Percival**：正义角色，替换一名 Loyal Servant；开局看到 Merlin 与 Morgana 两个候选座位，但无法区分。
- **Morgana**：邪恶角色，替换一名 Minion；参与邪恶阵营互认，并在 Percival 的视野中伪装成 Merlin。

成对启用不会改变任何人数下的正义/邪恶阵营数量。5 人局由 Merlin、Percival、一名 Loyal Servant、Assassin 和 Morgana 组成；6–10 人局继续按上表补足普通正义与邪恶角色。

以下角色仍不启用：

- **Mordred**：不会被 Merlin 看到。
- **Oberon**：不向其他邪恶玩家公开，也不获得其他邪恶玩家的身份信息。

角色配置在房间创建时公开确定并保持不变。旧房间缺少角色配置时继续使用基础角色，不随新默认值改变。
